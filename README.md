# AI Interview Coach (Spring Boot Backend)

The robust backend service built with Spring Boot to power the AI Interview Coach mobile application. It handles user authentication, connects with the Gemini AI LLM for interview questions & summaries, and stores history in a database.

## 🚀 Features
- **RESTful APIs:** Clean controllers structured for Authentication (`/api/auth`) and Interview modules (`/api/interview`).
- **AI Integration:** Generates dynamic technical interview questions and comprehensive performance evaluations using Gemini AI.
- **Database Persistence:** Stores user credentials and past interview history securely using Spring Data JPA.

## 🛠️ Tech Stack
- **Language:** Java
- **Framework:** Spring Boot (Web, Data JPA)
- **Database:** PostgreSQL / MySQL
- **AI Engine:** Google Gemini AI API
